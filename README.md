One line about the dumbest thing my agent did today: it spent 40 minutes re-downloading its login kit and asked me to approve a connection it already had — all to produce a single line. The program in `main.ts` writes that line (159 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
